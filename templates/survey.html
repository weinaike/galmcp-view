AI/Agent应用课程开发调研

关于这门课

背景：AI 的能力快速进化，AI使用方式也在变化，科研一线老师和同学们也期望熟练使用AI，因而计划开发这门AI应该普及课。

目标：让 AI/Agent 帮我们干活——课程讲的是如何使用 AI/Agent，不讲模型训练和微调。

课程内容大致包括：

  • LLM 基础知识
  • LLM API / SDK 使用方法
  • 工具的设计和封装方法
  • SKILL 的设计和封装方法
  • Agent 上下文管理方法
  • Agent 工作模式及实战应用（ReAct、Plan-and-Execute、Self-Reflection、Multi-Agent）
  • 知识库的构建与应用
